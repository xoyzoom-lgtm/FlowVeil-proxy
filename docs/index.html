Что это и что вам нужно

Клиент, а не сервис

FlowVeil сам ничего не «раздаёт». Он подключается к тому, что вы получили от своего провайдера, и управляет тем, как идёт трафик.

Это клиент, не сервис

У FlowVeil нет своих серверов, подписок и платного доступа. Приложение только подключается к вашим серверам и распределяет по ним трафик.

Нужна подписка от провайдера

Подписка — это ссылка вида https://…, которую выдаёт ваш провайдер или администратор. Скопируйте её и вставьте в FlowVeil: список серверов загрузится сам.

Android и Windows

Приложения для Android 7+ и Windows 10 / 11 (x64). Версий для iPhone, macOS и Linux пока нет.

        Маршрутизация
        
Каждому соединению — свой путь

        
Правила проверяются сверху вниз. Первое совпадение решает, куда пойдёт соединение.

      

      

        
direct
Локальная сеть и российские сервисы
Роутер, принтер, банки и маркетплейсы — без прокси и без задержек.

        
proxy
Всё остальное — через сервер
Выбранный вручную, самый быстрый или по правилу балансировки.

        
block
Реклама и трекеры
Отсекаются на уровне маршрутизации, до установки соединения.

      

    

  






  

    

      Режимы работы
      
Как FlowVeil перехватывает трафик

    

    

      
01 · TUN
Весь трафик
Виртуальный сетевой адаптер: через правила идёт трафик всех приложений, включая игры и мессенджеры.
Android · Windows (sing-box / gVisor / Xray)

      
02 · SYSTEM PROXY
Системный прокси
Браузер и приложения, которые уважают системный прокси. Не нужны права администратора.
Windows

      
03 · LOCAL
Локальный SOCKS / HTTP
Порт на 127.0.0.1 для своих программ, скриптов и других устройств в сети.
Android · Windows
