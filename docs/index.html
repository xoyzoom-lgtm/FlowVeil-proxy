      Режимы работы
      
Как FlowVeil перехватывает трафик

    

    

      
01 · TUN
Весь трафик
Виртуальный сетевой адаптер: через правила идёт трафик всех приложений, включая игры и мессенджеры.
Android · Windows (sing-box / gVisor / Xray)

      
02 · SYSTEM PROXY
Системный прокси
Браузер и приложения, которые уважают системный прокси. Не нужны права администратора.
Windows

      
03 · LOCAL
Локальный SOCKS / HTTP
Порт на 127.0.0.1 для своих программ, скриптов и других устройств в сети.
Android · Windows

      Вопросы
      
Частые вопросы

    

    

      
Прокси-клиент и маршрутизатор трафика — как v2rayN, v2rayNG или Happ. Своих серверов у FlowVeil нет: вы подключаете свои узлы или подписку, а FlowVeil управляет тем, как идёт трафик.

      
Share-ссылки (vless://, vmess://, trojan://, ss://, hysteria2://, tuic://, wireguard://), подписки в base64, Clash / Mihomo YAML, sing-box JSON и полные конфигурации Xray. Зашифрованные ссылки happ://crypt… открывает только приложение Happ.

      
TUN создаёт виртуальный сетевой адаптер, а это Windows разрешает только администратору. FlowVeil спрашивает разрешение один раз — дальше включает TUN сам. Системный прокси и локальный порт работают без прав.

      
Никаких: нет аккаунтов, аналитики и телеметрии. Источнику подписки уходят только стандартные заголовки устройства (для лимита устройств) — на Android их можно отключить. Политика конфиденциальности.
