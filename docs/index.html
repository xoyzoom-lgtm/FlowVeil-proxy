Частые вопросы

Это бесплатно?

Да. FlowVeil — бесплатное приложение с открытым кодом. Сами серверы даёт ваш VPN-провайдер.

Подписка не добавляется

FlowVeil покажет причину. Чаще всего ссылка открывает сайт, а не подписку — попросите у провайдера ссылку для приложения. Зашифрованные ссылки happ://crypt… открывает только приложение Happ.

Какие данные собирает приложение?

Никаких. Провайдеру подписки уходят только стандартные заголовки устройства для лимита устройств. Подробнее — в политике конфиденциальности.

Windows пишет «неизвестный издатель»

Установщик пока не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае». Сборки делаются автоматически из открытого кода.

Как провайдеру дать ссылку-приглашение?

Ссылка вида flowveil://add?url=ССЫЛКА_НА_ПОДПИСКУ открывает FlowVeil и сразу добавляет подписку.
