Вопросы

Частые вопросы

Да. FlowVeil — бесплатное приложение с открытым кодом. Серверы даёт ваш провайдер — у FlowVeil своих серверов нет.
FlowVeil покажет причину. Чаще всего ссылка открывает сайт, а не подписку — попросите у провайдера ссылку для приложения. Зашифрованные ссылки happ://crypt… открывает только приложение Happ.
Никаких. Провайдеру подписки уходят только стандартные заголовки устройства для лимита устройств; на Android их можно отключить.
TUN создаёт в Windows виртуальный сетевой адаптер, чтобы пустить через сервер весь трафик компьютера. Создавать адаптеры Windows разрешает только администратору, поэтому при первом включении TUN Windows один раз спросит разрешение — дальше FlowVeil включает TUN сам.
Ссылка вида flowveil://add?url=ССЫЛКА_НА_ПОДПИСКУ открывает FlowVeil и сразу добавляет подписку — на Android и Windows.
Минимум настроек на экране, автоматический выбор и переключение сервера, российские сервисы напрямую из коробки, напоминания о подписке и обновления в одно касание.
