# Модель угроз FlowVeil (кратко)

FlowVeil — клиент: серверов и аккаунтов у проекта нет. Защищаем то, что лежит на устройстве пользователя и что приходит извне.

| Что защищаем | От чего | Что сделано |
|---|---|---|
| Ссылки подписок и ключи серверов | Резервные копии системы, другие приложения | Android: `allowBackup=false`, правила извлечения данных; ID устройства скрыт в настройках |
| Импорт по ссылке / QR / буферу | Подсунутая ссылка, похожий домен, `javascript:`/`file:`/`intent:` | Окно «Добавить?» с хостом крупно, ничего не скачивается до нажатия, жёсткий разбор (`net/ImportPreview.kt`) |
| Обновления | Подменённый файл, откат на старую версию | Манифест с SHA-256 и размером, подпись ECDSA P-256 (переходный режим с вопросом), проверка ключа APK, папка пользователя на Windows |
| Трафик | Уход мимо сервера при сбое | Переключение между подписками выключено по умолчанию; системный «Блокировать без VPN» на Android |
| Автоматизация (Tasker) | Чужие приложения управляют подключением | Выключено по умолчанию, ключ задания |
| Сборка | Подмена зависимостей, утечка ключа подписи | Секреты только в release-job; тесты обязательны перед релизом; Dependabot; еженедельная сверка версий исходных проектов |

Чего FlowVeil не делает и не обещает: не скрывает факт использования прокси от оператора; не проверяет честность провайдера подписки; не защищает от вредоносного ПО на самом устройстве.

Что FlowVeil отправляет и куда — в `PRIVACY.md`.
