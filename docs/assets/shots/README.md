# Скриншоты для лендинга

Секция «Приложение изнутри» скрыта и появится сама, как только в `shots.json` появятся записи.

1. Положите файлы сюда (WebP: `cwebp -q 82 in.png -o out.webp`; телефон — до 1080 px по ширине, окно Windows — до 1600 px).
2. Добавьте их в `shots.json`, размеры — в пикселях самого файла (нужны, чтобы страница не «прыгала» при загрузке):

```json
{
  "android": [
    { "file": "android-1.webp", "caption": "Главный экран", "width": 1080, "height": 2340 },
    { "file": "android-2.webp", "caption": "Список серверов", "width": 1080, "height": 2340 }
  ],
  "windows": [
    { "file": "windows-1.webp", "caption": "Главное окно", "width": 1600, "height": 1000 }
  ]
}
```

Что снять: главный экран (подключено), список серверов с задержками, карточку подписки (срок, трафик), настройки.
Снимайте без личных данных: адресов серверов, имён подписок, IP.
