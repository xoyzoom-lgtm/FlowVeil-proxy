## Ссылки-приглашения и QR
- `flowveil://add`, `v2rayng://install-sub` и подобные: подписка **не добавляется без подтверждения**, показывается адрес; до нажатия «Добавить» ничего не скачивается и не отправляется (`ImportSource`, окно подтверждения; смешение алфавитов в адресе подсвечивается).
- Код переноса с компьютера (`flowveil://pair…`): открывает окно «выберите подписку», ничего не отправляет само; принимаются только адреса домашней сети (10.x, 172.16–31.x, 192.168.x), данные шифруются AES-256-GCM. **Найдено:** адрес домашней панели с путём `/p/…` принимался за код; **исправлено:** код определяется по секретной части.

## Буфер обмена
Читается один раз при открытии на экране, только предлагает добавить ссылку; отключается в настройках. Содержимое никуда не отправляется.

## Хранение данных
- Подписки, ключи и ID устройства лежат в хранилище приложения (MMKV, не зашифровано; защита — изоляция Android). Системная резервная копия и перенос на новый телефон отключены (`allowBackup=false`, правила исключения).
- **Не сделано:** шифрование хранилища. Это отдельная задача: нужно хранить ключ в Android Keystore и мигрировать существующие данные без потери подписок.

## Автоматизация (Tasker)
Выключена по умолчанию; команды принимаются только с секретным ключом из настроек.

## Известные ограничения
- Порт локального прокси при занятости переключается и запоминается навсегда; при быстром перезапуске службы он может «уезжать» вверх.
- Флаг «подключено» для выбора пути обновления может остаться устаревшим, если службу убила система: тогда первая попытка уйдёт в мёртвый прокси до таймаута.
- Windows: переключателя отправки ID устройства пока нет.
