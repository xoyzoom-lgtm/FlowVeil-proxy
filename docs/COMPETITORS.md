# Что есть у популярных клиентов и что есть у FlowVeil

Сравнение по возможностям (не по внешнему виду), по открытой информации о клиентах Happ, v2rayNG, v2rayN, Hiddify, NekoBox, v2RayTun, FlClash/Clash Meta. «Есть» — проверено по коду FlowVeil; на устройствах не проверялось.

| Несколько подписок, быстрый выбор | Happ, Hiddify, v2RayTun | есть (чипы/карточка) | есть (полоса подписок, группы) |

**Скорость** (что сделано по замерам, см. PROGRESS):
- DNS для сайтов «напрямую» по умолчанию был китайский (223.5.5.5 / 119.29.29.29 из исходников v2rayNG/v2rayN). Из России каждый такой запрос идёт в Китай и обратно, а сайты с CDN получают адрес не той страны. Теперь по умолчанию Яндекс (77.88.8.8); старое значение меняется один раз, если пользователь его не трогал.
- Размер буфера ядра (policy bufferSize 0/4/32/512 КБ): замерено локально через Xray 26.3.27 (vless, 400 МБ), разницы нет в пределах шума (0,8–1,2 ГБ/с во всех вариантах) — не меняли.
- MTU туннеля, время запуска, память — не замерено: нужен телефон (команды в OWNER-TODO.md).
