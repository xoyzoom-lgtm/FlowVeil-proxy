Перенос из другого приложения

Подписка живёт у вашего провайдера, а не в приложении. Чтобы пользоваться ею в FlowVeil, нужна та же ссылка подписки — обычный адрес, который начинается с https://. После переноса подписка продолжает работать и в старом приложении.

Из Happ

  1. Откройте Happ → подписка → «Поделиться».
  2. Выберите QR-код или «Скопировать ссылку».
  3. В FlowVeil нажмите «＋» → «Сканировать QR» или «Вставить из буфера».
Зашифрованная ссылка. Если ссылка начинается с happ://crypt, её может открыть только Happ — FlowVeil её не расшифровывает. Попросите у провайдера обычную ссылку подписки (https://…).

Ссылки вида happ://add/https://… FlowVeil понимает сам: адрес внутри будет показан перед добавлением.

Из v2rayNG

  1. Откройте v2rayNG → список подписок (меню «Группы» или «Подписки»).
  2. У нужной подписки: «Поделиться» → QR-код или «Скопировать ссылку».
  3. В FlowVeil: «＋» → «Сканировать QR» или «Вставить из буфера».

Есть резервная копия v2rayNG (.zip)? В FlowVeil «＋» → «Перенос из другого приложения» → «Из файла резервной копии v2rayNG» — FlowVeil возьмёт из неё только ссылки подписок.

Что происходит при добавлении

FlowVeil сначала показывает окно «Добавить подписку?» с адресом крупно. Пока вы не нажали «Добавить», ничего не скачивается и никуда не отправляется.

С телефона на компьютер

В FlowVeil на Windows откройте «Добавить» → «С телефона» и отсканируйте показанный QR-код в FlowVeil на телефоне: ссылка уйдёт по домашней сети, без облака. Оба устройства должны быть в одной сети.
