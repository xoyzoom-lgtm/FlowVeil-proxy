# Подпись установщика Windows (исследование)

Сейчас `FlowVeil-Setup.exe` **не подписан**, поэтому SmartScreen пишет «Неизвестный издатель». Это не признак вируса, но отпугивает. Варианты:

| Вариант | Цена | Что нужно | Минусы |
|---|---|---|---|
| **SignPath Foundation** (бесплатно для открытого кода) | 0 | Открытая лицензия OSI (у нас GPL-3.0), публичный репозиторий, поддерживаемый проект, уже выпущенные релизы, описание функций на странице загрузки, в проекте нет закрытых компонентов. Заявка отправляется через форму/письмо на signpath.org | Подпись идёт через их сервис из CI; сертификат выдаётся на имя SignPath Foundation, а не ваше; нужно выполнить их условия (в README — упоминание подписи и политика) |
| Свой сертификат OV/EV | от ~$200–500 в год (EV дороже) | Юрлицо или ИП, проверка документов | Деньги, документы; у OV репутацию SmartScreen всё равно набирают время |
| Azure Trusted Signing / Artifact Signing | около $10 в месяц | Проверка организации, есть ограничения по странам | Может быть недоступен для вашей страны |
| Без подписи | 0 | — | Предупреждение SmartScreen остаётся |

Что известно точно: условия программы описаны на https://signpath.org/terms.html (проверять перед подачей). Чего я не проверял: одобрят ли именно FlowVeil, и есть ли ограничения для автора из РФ — это решает SignPath.

## Что сделать владельцу (мне нужна ваша подача, я за вас её отправить не могу)

1. Открыть https://signpath.org/terms.html и https://signpath.org/ → форма заявки для открытых проектов, подать заявку на репозиторий `xoyzoom-lgtm/FlowVeil-proxy` (описание: «прокси-клиент для Android и Windows, GPL-3.0, форк v2rayN/v2rayNG»).
2. После одобрения: прислать мне организацию/проект в SignPath и токен CI — положить в секреты репозитория (`SIGNPATH_API_TOKEN`). Токен в чат не отправлять.
3. Я добавлю в `build.yml` шаг подписи `FlowVeil-Setup.exe` (и exe внутри портативной сборки) и в README строку про подпись.

Пока подпись не получена, в релизе лежит `SHA256SUMS.txt` — им можно проверить файл вручную.
