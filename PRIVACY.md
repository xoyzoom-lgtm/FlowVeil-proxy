# Политика конфиденциальности FlowVeil

Действует с 29 сентября 2026 г.
Разработчик: GxoyzoomG · Telegram: [@GxoyzoomG](https://t.me/GxoyzoomG)

FlowVeil — клиент для подключения к прокси-серверам по подписке (Android и Windows). У FlowVeil **нет своих серверов, аккаунтов и аналитики**: приложение работает только на вашем устройстве и само по себе ничего о вас не собирает и никуда не отправляет разработчику.

## 1. Что хранится на вашем устройстве

Всё хранится только локально, в папке приложения:

- ссылки на подписки и настройки серверов, которые вы добавили;
- сведения о подписке, которые прислал ваш провайдер (название, трафик, срок действия, объявление);
- настройки приложения (тема, режим подключения, маршрутизация);
- ID устройства (HWID) — короткая строка, созданная приложением при первом запуске (см. п. 2);
- журналы работы (логи) — только на устройстве, для поиска ошибок.

Разработчик не имеет доступа к этим данным. Они удаляются вместе с приложением.

## 2. Что FlowVeil отправляет вашему провайдеру

Когда вы добавляете или обновляете подписку, FlowVeil обращается по ссылке вашего провайдера и передаёт стандартные заголовки, по которым провайдер узнаёт устройство и ограничивает число устройств:

- `x-hwid` — ID устройства: необратимый хеш системного ID устройства (ANDROID_ID на Android, MachineGuid на Windows). По нему нельзя узнать ни сам системный ID, ни номер телефона, ни аккаунты; он нужен, чтобы после переустановки FlowVeil провайдер не считал телефон или ПК новым устройством;
- `x-device-os`, `x-ver-os`, `x-device-model` — система (Android/Windows), её версия и модель устройства;
- `User-Agent` — название клиента.

Отправку HWID можно отключить в настройках Android («Отправлять ID устройства»). Некоторые провайдеры без него не выдают серверы.

Что провайдер делает с этими данными, определяет **его** политика конфиденциальности. Трафик, который идёт через подключение, обрабатывает сервер провайдера, а не FlowVeil и не разработчик.

## 3. Другие сетевые запросы

- **GitHub** (github.com, api.github.com) — проверка и скачивание обновлений FlowVeil. GitHub видит ваш IP-адрес, как при обычном заходе на сайт.
- **Cloudflare (1.1.1.1) и Google (8.8.8.8)** — только на Windows и только если подписку не удалось скачать напрямую: через них по защищённому DNS (DNS-over-HTTPS) узнаётся адрес сервера подписки. Передаётся только имя сервера провайдера.
- **flagcdn.com** — только на Windows: картинки флагов стран в списке серверов. Передаётся только двухбуквенный код страны.
- **Проверка пинга и соединения** — тестовый запрос через выбранный сервер на адрес проверки из настроек.

## 4. Разрешения на Android

- **VPN (системный режим Android)** — чтобы пропускать трафик через выбранный сервер.
- **Уведомления** — чтобы показывать статус подключения.
- **Камера** — только для сканирования QR-кода подписки, когда вы сами это выбираете.
- **Установка приложений** — только чтобы установить скачанное вами обновление FlowVeil.
- **Автозапуск** — если вы включили запуск при включении устройства.
