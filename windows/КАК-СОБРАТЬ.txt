Hupp для Windows 11

1. Распакуй архив в папку, например C:\Hupp-src
2. Дважды кликни BUILD-Hupp.bat, подожди 3-10 минут
   (скрипт сам скачает .NET 10 SDK, ядро Xray и Inno Setup, если их нет)
3. Рядом появится Hupp-Setup.exe - это установщик.
   Запусти его: Далее -> Установить. Ярлык появится на рабочем столе и в Пуске.
   Hupp-Setup.exe можно скидывать на другие ПК: внутри уже всё есть,
   ничего ставить не надо (если ядра нет - установщик сам его скачает).
   Удаление: Пуск -> Hupp -> Удалить Hupp (или Параметры -> Приложения).

Подписка: Подписки -> Настройки подписок -> Добавить -> вставь ссылку -> ОК,
потом "Обновить подписки". HWID отправляется автоматически.
Темы: Настройки -> Тема (по умолчанию Happ · iOS 27 Glass, всего 17).
Включить VPN: внизу "Системный прокси" -> "Установить системный прокси".

Не нажимай "Проверить обновления -> v2rayN": это поставит оригинальный v2rayN поверх Hupp.
