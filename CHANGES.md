## Что изменилось

**Автоподбор рабочего сервера в мобильных сетях (Android)**
- Улучшен автоподбор: сначала выбираются серверы, подходящие для мобильных сетей (по названию, типу подключения и прошлым результатам), а не все подряд. Выбранные вручную проверяются так же.
- Каждый сервер проверяется до переключения на реальной мобильной сети. Если проверка после переключения не прошла, подключение возвращается на прежний сервер. Пока подходящий сервер не найден, ничего не меняется и приходит уведомление.
- В настройках можно проверить серверы на мобильной сети и увидеть отметки «Работал ✓» и «Не сработал ✗». Есть настройка, пробовать ли остальные серверы, если подходящих нет.
- Быстрее: уверенно подходящий сервер выбирается сразу, не дожидаясь остальных; серверы, которые уже работали здесь за сутки, не проходят долгую повторную проверку; проверка запускается сразу при включении экрана.
- В автоматическом режиме приложение честно предупреждает, что может ошибиться, и советует выбрать серверы самому.
- Проверка идёт через реальный порт профиля, поэтому серверы из JSON-конфигураций проверяются верно.
- Появился запрос на работу в фоне: без него некоторые прошивки (Xiaomi, OPPO, vivo, Huawei) «усыпляют» приложение.
- Карточка «Сеть» и журнал решений перенесены в режим разработчика; в журнале видно, почему выбран или пропущен сервер (без адресов).

**Перенос из другого приложения**
- Добавление по QR-коду, как на ТВ: FlowVeil показывает QR-код, вы открываете его камерой телефона (или на другом устройстве), вставляете на открывшейся странице ссылку подписки, и она приходит в FlowVeil. Работает на Android (в том числе на ТВ: меню «+» → «Перенос из другого приложения») и на Windows (Настройки → «Перенос из другого приложения»). Оба устройства должны быть в одной домашней сети; код действует, пока окно открыто.
- Android: подписки можно взять из файла резервной копии v2rayNG (читаются только ссылки, ваши данные не заменяются) или вставить ссылку из буфера.
- Windows: подписки из v2rayN на этом компьютере находятся сами (или выберите файл guiNDB.db); для Happ и других приложений вставьте ссылку из буфера.
- Из Happ подписку автоматически достать нельзя (данные приложения закрыты), зашифрованные ссылки не открываются: копируйте ссылку в Happ и отправляйте по QR или вставляйте.

**Шумы (мусорный трафик)**
- Новая настройка «Шумы» (Android: Настройки → Подключение; Windows: Настройки → Подключение): перед соединением отправляются случайные пакеты, чтобы его начало труднее было опознать. Работает с UDP-серверами (Hysteria2, mKCP); для серверов на TCP (VLESS Reality и др.) используйте фрагментирование. Немного увеличивает трафик, по умолчанию выключено, применяется при следующем подключении.

**Пинг**
- Пинг серверов по умолчанию идёт на gstatic, запасной адрес — Cloudflare.

**Windows**
- Пинг серверов появляется сразу: после запуска и обновления подписки все новые серверы проверяются сами, а после подключения пинг текущего сервера показывается числом и обновляется раз в 30 секунд. Без слов «работает / нет соединения»: только «123 мс» или «—».
- Режим TUN: установщик один раз просит разрешение Windows и создаёт задачу в Планировщике; дальше TUN включается без запросов и без ручного «запуска от администратора». Лишние пункты «Запустить от администратора» и «Сканировать QR-код с экрана» убраны из настроек.
- Убран пункт обновления «v2rayN»: он вёл на исходный репозиторий, а не на FlowVeil.
