## Что изменилось

**Ссылку на подписку можно добавить, даже когда сеть пропускает только белые списки (Android)**
- Если сервер подписки недоступен (мобильная сеть с белыми списками, сайт провайдера закрыт), ссылка всё равно сохраняется, и приложение сообщает об этом.
- Загрузка серверов повторяется сама: сначала через 20 секунд, потом реже (до раза в 5 минут), и при каждом открытии приложения. Как только что-то пропустит запрос (другая сеть, подключённый сервер), серверы появятся без ваших действий.
- Раньше после неудачной загрузки следующая попытка была только через весь интервал автообновления (по умолчанию 6 часов).

**Телефоны с 32-битной системой (Android)**
- Полная сборка `FlowVeil-android.apk` теперь содержит движок серверов TUIC для 32-битных телефонов (например, Samsung A12). Раньше на них TUIC не работал. Для 64-битных телефонов по-прежнему лучше `FlowVeil-android-arm64.apk`, он меньше.
