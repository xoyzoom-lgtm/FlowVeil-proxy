## Что изменилось

**Для провайдеров и администраторов**
- Ссылка-приглашение принимает название: `flowveil://add?url=…&name=Название`. Подписка сразу получает это имя (если панель присылает свой `profile-title`, показывается он). Android и Windows.
- Карточка подписки показывает кнопку «Сайт провайдера» из заголовка `profile-web-page-url` (рядом с «Поддержкой»). Принимаются только адреса http(s) (для поддержки ещё tg://).
- На сайте в разделе «Для провайдеров»: поле «Название для клиентов», «Лист для печати» (QR-код и три шага для клиента, можно распечатать или сохранить в PDF) и список заголовков, которые показывает приложение.
- Повторная ссылка на уже добавленную подписку на Android больше не создаёт вторую копию, даже если название в ссылке отличается.

**Переключение при сбое сервера**
- Windows: новое. Пока идёт подключение, FlowVeil каждые ~20 секунд проверяет, что трафик действительно проходит через сервер. Если сервер два раза подряд не отвечает (а сам компьютер в сети), приложение проверяет другие серверы (сначала из этой же подписки, потом из остальных рабочих), переключается на самый быстрый из отвечающих и сообщает об этом уведомлением. Российские серверы, выключенные и истёкшие подписки не предлагаются. Выключается в Настройках: «Переключаться при сбое сервера».
- Android: если в текущей подписке не нашлось рабочего сервера, пробуются серверы других подписок (настройка «Переключаться между подписками», по умолчанию включена); если рабочей замены нет совсем, приходит уведомление. Проверка стала чаще (раз в 20 секунд, пока экран включён).
