## Что изменилось

**Исправления по итогам проверки (Android)**
- Обновление скачивается и проверяется только по https: если файл или его проверочные данные перенаправляют на http, обновление отклоняется.
- Если закрыть окно обновления во время скачивания, больше не появляется ошибка «Не удалось скачать обновление».
- Список подписок сразу показывается целиком (раньше первый кадр был пустым).
- Адрес вашей домашней панели вида `http://192.168.x.x/p/…` больше не принимается за код переноса: код определяется по секретной части адреса.

**Журнал без секретов (Android и Windows)**
- В журнал больше не пишется адрес подписки целиком (в нём ключ доступа) и ответ провайдера при неудачном импорте: остаются только домен и длина ответа.
- Карточка подписки пишет «Не обновилась» и тогда, когда ошибку записала фоновая служба.

**Проверка скачанных файлов**
- В каждом релизе теперь есть `SHA256SUMS.txt`, в описании указан отпечаток сертификата подписи Android, а у сборок должно быть подтверждение происхождения (проверка: `gh attestation verify`). Команды проверки — в README.
- В README появились разделы «Что это и чего здесь нет» и «Как проверить скачанный файл»; добавлены CONTRIBUTING, шаблоны задач и `docs/SECURITY-REVIEW.md`.

Полная история изменений: `docs/CHANGELOG.md`.
