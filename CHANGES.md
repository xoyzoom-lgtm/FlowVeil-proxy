## Что изменилось

**Пинг: много способов проверки, как в других клиентах (Android)**
- В шторке «Пинг» теперь пять способов: «Через сервер (точно)», «Умный (TCP, затем через сервер)», «TCP», «TLS» и «ICMP». У каждого короткое пояснение.
- «Умный»: сначала быстрая проверка TCP, и только серверы, которые на неё ответили, проходят точную проверку через сервер. На длинных списках работает заметно быстрее и всё равно точно.
- «TLS»: подключение плюс TLS-рукопожатие. Показывает, что порт отвечает как настоящий веб-сервер, а не просто открыт.
- Для способов «Через сервер» и «Умный» есть режим «Лучший из двух»: два запроса, считается более быстрый. Второй запрос не тратит время на поиск адреса, поэтому число ближе к реальной скорости.
- Исправлено, из-за чего TCP показывал «не работает» у всех: серверы на UDP (Hysteria2, TUIC, WireGuard, HTTP/3) по TCP проверить нельзя, и их раньше помечало мёртвыми. Теперь они всегда проверяются через сервер. TCP стал надёжнее: у адреса с несколькими IP пробуются все (до трёх), при неудаче есть вторая попытка, поиск адреса ограничен по времени.
- Если быстрый способ (TCP, TLS или ICMP) не дал ответа ни у одного сервера из списка, значит, сам способ не работает в этой сети, а не все серверы мертвы: список автоматически проверяется ещё раз через сервер.
