# Что нужно сделать владельцу вручную

Что я не могу сделать за вас (ключи, аккаунты, заявки) или не стал делать без вашего решения.

## Подпись и доверие
1. **Ключ подписи обновлений** (ECDSA P-256): создать пару ключей, закрытый хранить офлайн, открытый передать мне для `UpdateKeys.kt` — шаги в `OWNER-TODO.md`. Пока ключа нет, приложение просит подтверждения при каждом обновлении.
2. **Подпись установщика Windows**: подать заявку в SignPath Foundation (бесплатно для открытого кода) или взять Azure Trusted Signing — шаги в `SIGNING.md`. Токен — в секреты репозитория, не в чат.
3. **Защита ветки `main`** (Settings → Branches): обязательные проверки сборки. Сейчас каждый пуш в `main` публикует релиз.
4. **Включить в репозитории**: Private vulnerability reporting (Settings → Security), Dependabot alerts, Code scanning (после первого запуска CodeQL).

## Сборка и цепочка поставки (не сделано)
- Закрепить GitHub Actions по хэшу коммита (`uses: …@<sha>`): мне недоступен поиск хэшей чужих репозиториев; можно включить через Dependabot (`github-actions`) или скриптом `pinact`.
- SBOM (CycloneDX) для Android и Windows: нужен подбор инструмента и проверка лицензии; не добавлял.
- CodeQL для Kotlin: нужна полная сборка Android в задаче анализа; пока только C# и workflows (`.github/workflows/codeql.yml`).
- Блокировка версий зависимостей (Gradle lockfiles, `packages.lock.json`): делается отдельной задачей, чтобы не сломать сборку.

## Дистрибуция (не сделано)
- F-Droid / IzzyOnDroid: нужны fastlane-метаданные (описания ru/en, скриншоты), проверка отсутствия несвободных зависимостей и заявка в их репозитории.
